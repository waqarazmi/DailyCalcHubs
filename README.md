# 🌍 DailyCalcHubs

> **Smart, Precision Online Financial & Expat Utilities for the GCC & Global Community.**

DailyCalcHubs is a modern, high-performance web utility platform engineered specifically for Gulf expats (Saudi Arabia, UAE, Qatar, Kuwait, Oman, Bahrain) and Non-Resident Indians (NRIs).

---

### ⚡ Core Features & Tools
* 💱 **Live Remittance & Currency Engine:** Real-time SAR to INR exchange tracking with provider breakdown (Barq, STC Pay, urpay).
* ⚖️ **Shariah-Compliant Zakat Calculator:** Precision Nisab calculation for gold, silver, cash, and business assets.
* 🇸🇦 **Saudi Expat Utilities:** End-of-Service Benefit (EOSB) calculator and 2026 Dependent Fee estimator.
* 🪙 **Precious Metals & Jewelry Tax:** Live 24K/22K gold estimation with 3% GST calculation.
* ✈️ **Travel Budgeting & Flight Planners:** Fast travel expenditure tools.

---

### 🛠️ Technology Stack
* **Frontend:** Clean Semantic HTML5, Modern CSS3, JavaScript (ES6+)
* **Performance:** Edge Caching via Cloudflare Pages
* **Compliance:** Fully compliant with Google AdSense, GDPR, CCPA, and COPPA standards.
